# 🍪 Cookie Clicker - Java Edition

Ein süchtig machendes Cookie-Clicking-Spiel in Java mit GUI!

## 🎮 Features

- 🖱️ **Großer klickbarer Cookie** - Der Hauptbutton zum Klicken
- 🏢 **8 verschiedene Upgrades** - Cursor, Großmutter, Farm, Mine, Fabrik, Bank, Magier, Portal
- ⏱️ **Automatische Cookie-Generierung** - Passive Einkommen pro Sekunde
- 📈 **Exponentiell steigende Kosten** - Jedes Upgrade wird 1.15x teurer
- 🎨 **Schöne GUI** - Mit Farben und Formatierung
- 📊 **Live CPS-Anzeige** - Zeigt deine Cookies pro Sekunde an

## 📥 Installation

### Windows 🪟
1. Alle Dateien in einen Ordner speichern
2. `start.bat` mit **Doppelklick** starten
3. Fertig! Das Spiel startet automatisch

### Mac/Linux 🍎🐧
1. Alle Dateien in einen Ordner speichern
2. Im Terminal:
   ```bash
   chmod +x start.sh
   ./start.sh
   ```

### Manual (Alle Systeme)
```bash
javac CookieClicker.java
java CookieClicker
```

## 🎯 Gameplay

1. **Klicke auf den großen Cookie** um Cookies zu verdienen
2. **Kaufe Upgrades** um passive Einkommen zu generieren
3. **Verdiene mehr Cookies** durch automatische Generierung
4. **Entsperre neue Upgrades** mit höheren Werten
5. **Steigere dein Einkommen** exponentiell!

## 💡 Tipps

- Kaufe Upgrades in aufsteigender Reihenfolge für optimales Einkommen
- Achte auf die grünen Buttons - das bedeutet, du kannst es dir leisten!
- Der Magier und das Portal sind der Schlüssel zu passivem Reichtum
